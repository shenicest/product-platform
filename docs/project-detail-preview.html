项目介绍

WorthBloom·好好花是一款面向消费决策与购买后价值追踪的产品，关注用户在课程、会员、数码产品、旅行及体验类消费中常见的“想买但不确定值不值”“买完后又没有真正使用”等问题。用户可以创建心愿、比较多个候选产品、邀请朋友参与讨论，并结合 AI 建议做出购买、存钱或等待的决定。购买后，产品继续记录使用次数、余额、有效期及 Cost per Use，让一次消费从付款瞬间延伸为“想清楚、做决定、持续使用、验证价值”的完整过程。

现场成果

团队完成了移动端 PWA 的核心产品闭环，包括心愿创建、截图与链接信息提取、多商品比较、朋友免登录回信、AI 建议与 Agent 对话、存钱目标、购买后物资管理、使用记录和成长积分。同时完成 ESP32-S3 电子花的软硬件联动接口，将存钱、购买和使用状态映射为实体花朵的成长状态。
