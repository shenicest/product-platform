# BoomLand V2.6 设计稿落地：页面与冲突说明

> 设计稿：`C:\Code\NewBoomland`（BoomLand V2.6 交互原型，纯 HTML/CSS/JS）。
> 本次改版范围：**火热赛季落地页 / 赛季详情页 / 命题详情页 / 报名表单 / 个人中心**。
> 数据接口与业务逻辑未改动（只改样式、版式与入口路由）。
>
> 最终状态：前四页按设计稿落地；**个人中心在评审后回滚到改造前的版本**
> （页头 + 横向 tab），未采用设计稿的粉色侧栏外壳，原因见 §2.8。

## 1. 页面映射

| 设计稿页面 | 设计稿路由 | 本项目路由 | 实现方式 |
| --- | --- | --- | --- |
| 火热赛季（落地页） | `#seasons` | `/seasons` | 服务端取列表 → 客户端首屏切换 + 筛选 + 票券墙 |
| 赛季详情 | `#season?code=` | `/seasons/[id]` | 独立路由；点击票券整卡进入 |
| 命题详情 | `#challenge?id=` | `/challenges/[id]` | 保留原有 6 个 tab 与右栏 |
| 报名表单 | `#apply` | `/seasons/[id]/apply` | 表单字段与提交逻辑不变 |
| 个人中心 | `#workspace` | `/me/*` | 回滚到改造前：页头 + 横向 tab |

**结构性变更**：旧版 `/seasons` 把「赛季详情」塞进同一页的左右滑动轮播里（`?season=<id>`）。
新版按设计稿拆成两层：

- `/seasons` 只做落地页：推荐首屏 + 四个筛选 + 赛季票券墙；
- `/seasons/:id` 是唯一的赛季详情页，票券卡整卡链接到它。

`/seasons?season=<id>` 的旧链接已没有「轮播定位」语义。仓库内所有指向它的入口
（`lib/me-applications.ts`、`components/boomland/my-applications.tsx`）已改为 `/seasons/:id`，
对应单测同步更新；外部旧书签访问 `/seasons?season=<id>` 时由落地页 `redirect()` 到独立详情页。

## 2. 与当前项目冲突、按「保留产品事实」处理的设计项

下面每一条都是设计稿有、但按当前项目的数据/路由/品牌无法一比一还原的地方。
处理原则：**不伪造数据、不新增业务行为、不破坏全站一致**；在样式允许的范围内贴近设计稿。

### 2.1 站点外壳（页头 / 页脚 / 品牌）

| 设计稿 | 当前项目 | 处理 |
| --- | --- | --- |
| BoomLand 字标 + 76px 页头 + 主导航（大厅 / 火热赛季 / 产品共生 / 共鸣之地 / 排行榜） | SheNicest 字标 + 73px 页头 + 主导航（产品共生 / 火热赛季 / 共鸣之地 / 黑客松 / 我的关注） | **完全保留全站页头/页脚**：品牌、导航、页头与页脚底色都沿用「生长」皮肤，不在这几个页面改背景色。 |
| 页脚「BoomLand / 让真实行动留下记录」 | 页脚「SHE NICEST · 产品生长之地」 | 保留现有页脚文案与链接。 |
| 导航高亮当前页 | 全站导航没有 active 态 | 未在本批新增（属于全站 header 行为，不在 5 页范围内）。 |

### 2.2 字体

- 设计稿：`Inter / Noto Sans SC / PingFang SC`，标题常用 `font-weight: 950`。
- 项目：Harmony Sans（`--font-harmony`，本地字体，只有 400/700/900 三档）+ Monocraft。
- 处理：**沿用 Harmony**。标题统一 900（设计稿的 950 在 Harmony 里不存在，浏览器会合成加粗），
  不引入第二套字体，避免全站字体加载与字重抖动。

### 2.3 配色作用域

设计稿把粉 / 纸白写进全局 `:root`。本项目已经有一套全站「生长」皮肤（冷白云底 + 绽放粉），
如果直接改全局 token，会影响产品共生、人才、黑客松等页面。

- 处理：新增 L0 变量 `--boom-v26-*`（`styles/skins/boomland.css`），在 `.v26` 作用域里
  映射成 `--v26-*`，由 `styles/v26.css` 消费。5 个页面根节点带 `.v26`。
- 页面底色、页头与页脚**不覆盖**：全部沿用全站「生长」皮肤的 `--bg` / `--bg-elevated`，
  与产品共生、人才等页面一致。`.v26` 只提供组件级颜色 token，自身背景保持透明。
